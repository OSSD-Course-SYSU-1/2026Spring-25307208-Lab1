# 🎲 趣味计算器 — 功能说明

> 基于 HarmonyOS  ArkUI 开发的趣味娱乐计算器，在标准计算器基础上加入了**随机错误彩蛋**，让每次计算都充满惊喜！

## 🧮 核心功能

### 1. 标准计算功能

- **四则运算**：支持加法（`+`）、减法（`-`）、乘法（`×`）、除法（`÷`）
- **百分比计算**：支持 `%` 运算符，自动将数值转换为百分比
- **小数输入**：支持小数点 `.` 输入与运算
- **连续运算**：支持多步表达式连续计算
- **运算符优先级**：正确遵循先乘除、后加减的运算规则
- **科学计数法**：超长结果自动转换为科学计数法显示（如 `1.23e+10`）

### 2. 输入控制

- **AC 清空**（`C` 图标按钮）：一键清空所有输入和结果
- **DEL 退格**（`⌫` 图标按钮）：逐字符删除输入
- **输入校验**：
  - 不允许以 `%` 开头
  - 不允许连续输入多个小数点
  - 不允许数字以 `0` 开头后直接跟非小数点字符（如 `05`）
  - 已含 `%` 的数字不能再追加 `%`
- **千分位格式化**：输入和结果自动添加千分位逗号分隔（如 `1,234,567`）
- **自适应字号**：输入超过 9 位时自动缩小字体以适配显示区域

### 3. 趣味娱乐模式 🎯

这是本计算器的**核心特色功能**，默认为开启状态：

#### 随机错误机制
- 每次计算结果都有 **30% 的概率** 被随机篡改
- 篡改幅度：在正确结果上随机增减 **1~5** 个单位
- 篡改方向随机（加或减）

#### 趣味提示语句
当随机错误发生时，界面底部会显示一条随机的趣味语句：

| # | 趣味语句 |
|---|---------|
| 1 | 系统打了个盹，结果可能跑偏了~ |
| 2 | 刷新一下，让计算器清醒清醒！ |
| 3 | 这个结果...我觉得它需要再想想。 |
| 4 | 娱乐模式启动，计算结果仅供参考哦！ |
| 5 | 好像哪里不对，要不再算一次？ |
| 6 | 计算器今天心情不好，结果随缘~ |
| 7 | 别太认真，就是个娱乐计算器嘛！ |
| 8 | 再算一次说不定就对了（也不一定） |

#### 刷新重算按钮（🎲 刷新重算）
- 当发生随机错误时，**「🎲 刷新重算」按钮** 变为可用（红色）
- 点击后可重新计算当前表达式
- 重新计算时仍然有概率再次触发随机错误
- 若计算正确，按钮恢复为禁用状态（灰色），并提示"这次算对了！"

#### 等号运算的精确模式
- 按下 **等号（=）** 执行最终运算时，会自动**临时禁用**随机错误
- 确保等号结果 100% 精确
- 等号运算后自动清除趣味语句、禁用刷新按钮

## 🖥️ 界面布局

### 显示区域（从上到下）
1. **输入显示区** — 显示当前输入的表达式（支持千分位格式化）
2. **结果预览区** — 实时显示当前表达式的计算结果
3. **趣味消息区** — 显示随机趣味语句（仅在触发错误时出现）
4. **刷新按钮区** — 「🎲 刷新重算」按钮
5. **按键面板** — 4×5 网格布局的功能按钮

### 按键布局

| 行 | 按键 |
|----|------|
| 第 1 行 | `C`（清空） | `7` | `4` | `1` | `%` |
| 第 2 行 | `÷`（除法） | `8` | `5` | `2` | `0` |
| 第 3 行 | `×`（乘法） | `9` | `6` | `3` | `.` |
| 第 4 行 | `⌫`（退格） | `−`（减法） | `+`（加法） | `=`（等号） |

> `=` 键采用双倍宽度设计，视觉效果更突出

## 🔧 技术架构

### 项目结构

```
entry/src/main/ets/
├── pages/
│   └── HomePage.ets              # 主页面（UI 布局 + 交互逻辑）
├── common/
│   ├── constants/
│   │   └── CommonConstants.ets    # 常量定义（运算符、优先级等）
│   └── util/
│       ├── CalculateUtil.ets      # 核心计算引擎（含随机错误注入）
│       ├── CheckEmptyUtil.ets     # 空值校验工具
│       └── Logger.ets             # 日志工具
└── viewmodel/
    ├── PressKeysItem.ets          # 按键数据模型
    └── PresskeysViewModel.ets     # 按键布局配置
```

### 核心技术点

| 技术 | 说明 |
|------|------|
| **UI 框架** | HarmonyOS ArkUI（声明式 UI） |
| **语言** | ArkTS（TypeScript 扩展） |
| **状态管理** | `@State` 装饰器驱动 UI 响应式更新 |
| **计算引擎** | 调度场算法（Shunting-yard）实现中缀表达式求值 |
| **随机错误** | 在 `CalculateUtil` 的加减乘除方法中注入随机逻辑 |
| **资源管理** | `$r()` 引用资源文件，支持中英文多语言 |
| **科学计数法** | 超长数值自动转换，避免精度溢出 |
